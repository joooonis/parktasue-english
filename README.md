# 박태수영어 Signature 백지테스트

내신영어 인터랙티브 빈칸 테스트 웹앱. 학생이 브라우저에서 지문의 빈칸을 채우고 즉시 채점받을 수 있습니다.

빌드 과정이나 서버 없이 동작하는 **단일 HTML 파일**입니다 (`index.html`).

## 사용 방법

1. `index.html`을 더블클릭해서 브라우저로 바로 열거나
2. 이 저장소에 GitHub Pages를 켜면 별도 서버 없이 웹 링크로 바로 접속 가능합니다:
   - **Settings → Pages → Source: `main` 브랜치 / `/ (root)` 폴더** 선택 후 저장
   - 잠시 후 `https://[깃허브아이디].github.io/[저장소이름]/` 주소로 접속 가능

## 주요 기능

- 지문 붙여넣기 → 난이도(기본/심화/통암기) 선택 → 자동 빈칸 생성
- 문장별 한글 해석 동시 표시
- 실시간 채점 + 정답/오답 색상 표시
- 빈칸 테스트지 PDF 인쇄 저장
- (Claude 아티팩트 환경 전용) 지문 보관함, 학생 제출 현황 대시보드

## 개발 문서

코드 구조, 함수 맵, 알려진 제약사항은 [`HANDOFF.md`](./HANDOFF.md)를 참고하세요.

## 기술 스택

Vanilla HTML/CSS/JS, 프레임워크·빌드 도구 없음. 외부 의존성은 Google Fonts, Pretendard 웹폰트뿐입니다.
